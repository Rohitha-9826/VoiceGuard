# VoiceGuard

An AI-powered Deepfake Audio Detection System using CNN-BiLSTM and Explainable AI.

## Tech Stack

- Python
- PyTorch
- Librosa
- Scikit-learn
- SHAP
- LIME
- FastAPI
- React
